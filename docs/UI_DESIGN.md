# HabitLoop UI/UX 线框图设计

## 设计规范

### 配色方案

| 用途 | 浅色模式 | 深色模式 |
|------|----------|----------|
| **主背景** | #FFFFFF | #121212 |
| **次级背景** | #F5F5F5 | #1E1E1E |
| **卡片背景** | #FFFFFF | #2C2C2C |
| **主文字** | #1A1A1A | #FFFFFF |
| **次级文字** | #666666 | #B0B0B0 |
| **强调色 (主)** | #4CAF50 | #81C784 |
| **强调色 (次)** | #2196F3 | #64B5F6 |
| **警告色** | #FF9800 | #FFB74D |
| **错误色** | #F44336 | #E57373 |
| **分割线** | #E0E0E0 | #424242 |

### 主题色 (习惯颜色选项)
- 绿色 #4CAF50 - 健康/运动
- 蓝色 #2196F3 - 学习/工作
- 橙色 #FF9800 - 创意/阅读
- 紫色 #9C27B0 - 冥想/成长
- 红色 #F44336 - 紧急/重要
- 青色 #00BCD4 - 生活/其他

### 字体规范
- **大标题:** 24sp, Bold
- **页面标题:** 20sp, SemiBold
- **正文:** 16sp, Regular
- **辅助文字:** 14sp, Regular
- **小字:** 12sp, Light

## 交互动效

### 打卡成功动效
- 点击打卡按钮 → 按钮缩放 + 颜色变化
- 撒花/星星粒子效果 (可选)
- 轻微震动反馈 (haptic feedback)
- Streak 数字滚动更新

### 页面切换
- 左右滑动切换底部 Tab
- 从右向左推入新页面
- 模态页面从底部弹出

### 数据加载
- 骨架屏 (skeleton) 占位
- 下拉刷新动画
- 空状态插图 + 引导文字

## 适配规范

### 屏幕尺寸
- 最小支持：4.7 英寸 (iPhone SE)
- 优化支持：6.7 英寸 (iPhone Pro Max)
- 平板适配：iPad 分屏模式

### 深色模式
- 所有页面支持深色模式
- 跟随系统设置自动切换
- 手动切换开关 (设置中)

### 无障碍
- 支持动态字体大小
- VoiceOver/TalkBack 标签
- 颜色对比度符合 WCAG 2.1 AA
