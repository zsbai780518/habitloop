# HabitLoop V1.5 社区功能设计方案

**版本:** V1.5  
**目标:** 增加社交互动功能，提升用户留存和活跃度  
**开发周期:** 3 周

---

## 一、功能概述

V1.5 版本核心是引入社区挑战功能，让用户在个人习惯追踪的基础上，能够参与集体挑战、与好友互动，形成社交激励机制。

### 核心功能
1. **社区挑战** - 官方发起热门挑战，用户参与打卡
2. **好友系统** - 邀请好友、查看动态、互相鼓励
3. **排行榜** - 挑战参与者的打卡排名
4. **动态分享** - 分享打卡成果到挑战动态

## 二、技术架构

### 2.1 技术选型

| 模块 | 技术方案 | 说明 |
|------|----------|------|
| 后端服务 | Firebase | 用户认证、云数据库、云存储 |
| 实时通信 | Firebase Firestore | 挑战数据、好友关系实时同步 |
| 推送通知 | Firebase Cloud Messaging | 挑战提醒、好友互动通知 |
| 图片存储 | Firebase Storage | 用户头像、挑战封面图 |
| 广告变现 | AdMob | 开屏广告、信息流广告 |

## 四、Firebase 集成方案

### 4.1 项目配置

```yaml
# pubspec.yaml 新增依赖
dependencies:
  firebase_core: ^2.24.0
  firebase_auth: ^4.16.0
  cloud_firestore: ^4.14.0
  firebase_storage: ^11.6.0
  firebase_messaging: ^14.7.0
  google_sign_in: ^6.2.0
```

### 4.2 初始化流程

```dart
// lib/services/firebase_service.dart
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_auth/firebase_auth.dart';
import 'package:cloud_firestore/cloud_firestore.dart';

class FirebaseService {
  static Future<void> initialize() async {
    await Firebase.initializeApp();
  }

  static FirebaseAuth get auth => FirebaseAuth.instance;
  static FirebaseFirestore get firestore => FirebaseFirestore.instance;
  static Future<UserCredential> signInAnonymously() {
    return auth.signInAnonymously();
  }
}
```

### 4.3 数据同步策略

- **离线优先:** 本地 SQLite 仍是主要数据存储
- **选择性同步:** 仅同步挑战相关数据到云端
- **冲突处理:** 以本地数据为准，云端作为备份
- **隐私保护:** 用户可选择是否加入社区功能

## 五、AdMob 广告集成

### 5.1 广告位设计

| 位置 | 广告类型 | 展示频率 |
|------|----------|----------|
| 启动页 | 开屏广告 | 每次启动 |

- 订阅用户 ($4.99/月) 移除所有广告
- 订阅状态通过 Firebase Remote Config 管理
- 提供 7 天免费试用

## 八、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| Firebase 服务不稳定 | 用户体验差 | 降级为纯离线模式 |
| 社区内容审核 | 合规风险 | 敏感词过滤 + 举报机制 |
| 用户隐私泄露 | 信任危机 | 最小化数据收集 + 加密存储 |
| 服务器成本超支 | 财务压力 | 设置用量告警 + 限流 |
