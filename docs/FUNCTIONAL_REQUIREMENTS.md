# HabitLoop 核心功能需求拆解

## P0 级功能 (V1.0 必须完成)

### 1. 习惯管理模块

#### 1.1 创建习惯
**功能描述:** 用户可以创建新的习惯，设置名称、图标、颜色、频率等属性。

**输入:**
- 习惯名称 (必填，1-50 字符)
- 图标 (必填，从预设图标库选择)
- 颜色 (必填，从预设色板选择)
- 打卡频率 (必填：每天/每周/自定义)
- 每日目标次数 (选填，默认 1)
- 提醒设置 (选填：启用/时间)
- 备注 (选填，0-200 字符)

**验证规则:**
- 名称不能为空
- 同一用户不能有完全重名的习惯
- 频率值必须合法

**输出:** 创建成功的习惯对象，存入数据库

---

#### 1.2 编辑习惯
**功能描述:** 用户可以修改已有习惯的所有属性。

**前置条件:** 习惯已存在且未删除

**可编辑字段:** 除创建时间外的所有字段

**特殊逻辑:**
- 修改频率不影响历史打卡记录
- 修改颜色/图标立即生效
- 删除习惯采用软删除 (保留历史记录)

---

#### 1.3 删除习惯
**功能描述:** 用户可以删除不再需要的习惯。

**删除类型:**
- 软删除：默认操作，隐藏习惯但保留历史数据
- 硬删除：设置中提供"彻底删除"选项，清空所有相关数据

**删除确认:** 弹出二次确认对话框

---

#### 1.4 习惯列表展示
**功能描述:** 首页展示所有启用状态的习惯列表。

**展示内容:**
- 习惯图标、名称、颜色
- 当前连续打卡天数 (Streak)
- 今日打卡状态 (已打卡/未打卡)
- 打卡按钮

**排序规则:**
- 默认：按创建时间倒序
- 可选：按名称字母序、按完成率

**筛选规则:**
- 全部习惯
- 今日需打卡习惯 (根据频率过滤)

---

### 2. 打卡功能模块

#### 2.1 一键打卡
**功能描述:** 用户点击按钮完成当日习惯打卡。

**前置条件:**
- 习惯处于启用状态
- 当日尚未完成目标次数

**打卡逻辑:**
1. 检查今日是否已打卡
2. 创建打卡记录 (含时间戳)
3. 更新连续打卡天数
4. 触发成功动效 + 震动反馈
5. 刷新 UI 状态

**幂等性:** 同一习惯同一日多次打卡需处理 (累加次数或提示已完成)

---

#### 2.2 补卡功能
**功能描述:** 用户可以补充过往日期的打卡记录。

**限制规则:**
- 免费版：每月 3 次补卡机会
- 只能补过去 7 天内的记录
- 不能补未来日期

**补卡流程:**
1. 进入习惯详情页
2. 点击历史日期 (未打卡)
3. 确认补卡
4. 扣减补卡次数
5. 更新 Streak (如适用)

---

#### 2.3 Streak 计算
**功能描述:** 计算并展示连续打卡天数。

**计算逻辑:**
```
当前 Streak = 从今天往前连续打卡的天数
历史最长 Streak = 所有连续打卡区间的最大长度
```

**边界情况:**
- 今天未打卡：Streak 中断，显示历史最长
- 新建习惯：Streak 从 0 开始
- 补卡：可恢复中断的 Streak

**存储方式:** 实时计算 (不单独存储，避免数据不一致)

---

### 3. 数据统计模块

#### 3.1 周/月总结
**功能描述:** 自动生成周/月度数据统计报告。

**统计维度:**
- 本周/月打卡总次数
- 平均完成率 (实际打卡天数 / 应打卡天数)
- 每个习惯的完成率
- 最佳表现习惯 (完成率最高)
- 需改进习惯 (完成率最低)

**展示形式:**
- 文字总结 (自动生成文案)
- 柱状图 (每日打卡次数)
- 饼图 (各习惯占比)

**生成时间:**
- 每周一生成上周总结
- 每月 1 号生成上月总结
- 用户可手动查看任意周期

---

#### 3.2 数据可视化图表
**功能描述:** 用图表直观展示打卡趋势。

**图表类型:**
1. **柱状图:** 每日/每周打卡次数
2. **折线图:** Streak 变化趋势
3. **环形图:** 各习惯完成率分布
4. **热力图:** 打卡日历 (类似 GitHub)

**交互:**
- 点击图表元素查看详情
- 支持缩放、滑动
- 支持切换时间范围 (周/月/年)

---

### 4. 本地通知模块

#### 4.1 提醒设置
**功能描述:** 用户可以为每个习惯设置打卡提醒。

**设置项:**
- 启用/禁用开关
- 提醒时间 (时：分)
- 重复周期 (每天/工作日/自定义)

**存储:** 存入 habits 表 reminder_enabled 和 reminder_time 字段

---

#### 4.2 本地推送
**功能描述:** 在设定时间推送本地通知提醒用户打卡。

**技术方案:** flutter_local_notifications

**通知内容:**
- 标题：习惯名称 + "打卡时间到!"
- 正文：鼓励文案 + 连续天数
- 操作：快速打卡按钮 (可选)

**离线支持:** 本地通知不依赖网络，离线正常推送

**权限:** 首次使用请求通知权限

## 非功能需求

### 性能指标
| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 冷启动时间 | ≤2s | 从点击图标到首页可交互 |
| 打卡响应时间 | ≤200ms | 点击到 UI 更新完成 |
| 页面切换 | ≤300ms | 路由切换动画完成 |
| 数据库查询 | ≤100ms | 习惯列表加载 |

### 兼容性
- Android 8.0+ (API 26+)
- iOS 12+
- 屏幕尺寸：4.7" - 6.7"
- 深色模式：完整支持

### 数据安全
- 本地数据库加密 (可选)
- 不收集用户身份信息
- 支持数据导出 (JSON/CSV)
- 支持数据彻底删除
